## Отличия копии от страницы на сайте

1. Файлы подключаются из репозитория по относительным путям.
2. Ссылки меню и подвала ведут на страницы агерис.рф.
3. В плашке города стоит «Москва». Сервер подставляет город по IP посетителя, а копия снималась с сервера в США.
4. Вне домена агерис.рф не загружаются Яндекс Метрика, UIS (CoMagic), Botfaqtor и Radist, а формы показывают сообщение вместо отправки заявки. На агерис.рф этот код работает как на боевой странице.

Canonical и мета-теги указывают на агерис.рф/audit.

## Ускорение загрузки

1. Фото первого экрана — WebP шириной 1280–2560 px вместо JPG на 2,1 МБ. Оно загружается сразу и с высоким приоритетом, а не «лениво». На телефонах, где фото скрыто, оно не скачивается.
2. Остальные изображения переведены в WebP: исходные JPG были сохранены с качеством 100. Крупные картинки получили адаптивные размеры (`srcset`) и загружаются по мере прокрутки (`loading="lazy"`). QR-код сохранён в WebP без потерь.
3. В иконке Max встроенная картинка 1000×1000 уменьшена до 108×108: файл стал весить 11 КБ вместо 331 КБ.
4. Шрифты подключаются из репозитория, а не с Google Fonts, используемые файлы подгружаются заранее. Literata прямого начертания на странице используется только толщиной 700. Поэтому её файлы зафиксированы на 700, при этом форма букв и оптические размеры прежние. Латинский набор Literata разделён на знаки и буквы, и браузер скачивает только знаки.
5. jQuery и Fancybox подключаются из репозитория в тех же версиях; jQuery перенесён из `<head>` в конец страницы. Swiper удалён: слайдеров на странице нет.
6. Фон блока заявки — WebP (22 КБ вместо 450 КБ) с запасным JPG для старых браузеров.
7. Добавлены описание страницы (`meta description`) и подписи для ссылок-иконок.

Вес страницы при загрузке снизился с 7,5–9,6 МБ примерно до 0,6 МБ.

## Что перенести на агерис.рф

Правки затрагивают шаблон `page-audit.php`, `assets/css/style.css` и файлы в `assets/`. Кроме них на сайте стоит:

- подключить Botfaqtor асинхронно: сейчас он подключён синхронно в `<head>` и задерживает отрисовку страницы;
- включить на сервере долгое кеширование изображений, шрифтов, CSS и JS — на GitHub Pages это не настраивается;
- задать описание страницы в All in One SEO.
