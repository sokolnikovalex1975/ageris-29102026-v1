# АГЕРИС — пест-менеджмент по ХАССП: текущая версия агерис.рф/audit

Копия страницы [агерис.рф/audit](https://агерис.рф/audit/) в том виде, в каком она опубликована на сайте 28 октября 2026 года. На сайте страница работает на WordPress: тема `ageris`, шаблон `page-audit.php`, форма Contact Form 7 № 148.

Просмотр: https://sokolnikovalex1975.github.io/ageris-audit-live/

## Что внутри

| Путь | Содержимое |
|---|---|
| `index.html` | HTML страницы, который отдаёт сервер агерис.рф |
| `wp-content/themes/ageris/assets/` | стили, скрипты и изображения темы; структура папок такая же, как на сайте |
| `wp-content/plugins/contact-form-7/` | стили и скрипты формы заявки |
| `wp-includes/js/dist/` | служебные скрипты WordPress для формы |
| `favicon.svg` | иконка сайта |

jQuery, Swiper, Fancybox и шрифты Google Fonts подключаются с CDN, как на сайте.

## Отличия от страницы на сайте

Первый коммит содержит HTML без изменений. Во втором коммите сделаны правки для GitHub Pages:

1. Файлы темы подключаются из репозитория по относительным путям.
2. Ссылки меню и подвала ведут на страницы агерис.рф.
3. В плашке города стоит «Москва». Сервер подставляет город по IP посетителя, а копия снималась с сервера в США.
4. Вне домена агерис.рф не загружаются Яндекс Метрика, UIS (CoMagic), Botfaqtor и Radist, а формы показывают сообщение вместо отправки заявки. На агерис.рф этот код работает как на боевой странице.

Тексты, вёрстка, стили и изображения не менялись. Canonical и мета-теги указывают на агерис.рф/audit.
